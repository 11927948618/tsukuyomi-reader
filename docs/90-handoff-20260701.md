## 重要な設計判断

### 1. 通常読書画面はブラウザ組版を使う

手計算だけで縦書きページを作ると、ルビ、禁則、句読点、傍点、ダッシュ、端末差で破綻しやすいです。

現在の方向性は、CSS の `writing-mode` / `ruby` / `text-orientation` を使い、ページ境界や収まりだけを JavaScript 側で管理する方針です。

### 2. 400字詰め表示は捨てた

400字詰めそのものを表示目標にすると、実画面の読みやすさと衝突します。

今後やるなら、ライブラリや作品情報で「400字詰め換算 N 枚」を表示するだけで十分です。本文表示の基準にはしないでください。

### 3. 文字特化で進める

MP3 埋め込みや TsukuyomiPlayer 構想は廃案です。将来別サービスにするなら Reader とは分けます。

### 4. R2 / Cloudflare の負荷を増やさない

表示設定や読書中の状態は、基本的にブラウザ側の保存で済ませます。保存ボタンや読書ログでサーバーへ送る必要があるものだけ送ります。ページ送りや表示確認のたびに通信する設計にはしないでください。

## 表示まわりの現在仕様

### ページ方向

- 縦書き:
  - 右端が開始位置。
  - 読む方向は右から左。
  - スライダも右端始点。
  - タップは「上または右で戻る」「下または左で進む」。
- 横書き:
  - 左端が開始位置。
  - 読む方向は左から右。
  - スライダも左端始点。
  - タップは「下または右で進む」「上または左で戻る」が自然。

### ページ切替とスクロール

メニューは最終的に「ページ送り」と「スクロール」の二択へ寄せる方針です。

以前は縦スクロール、横スクロール、ページ切替が分かれていましたが、UI と実装の両方で混乱が大きくなりました。今後は表示方向とページ進行方向を分けて考えてください。

### 段組み

段組み許可オプションはありますが、安定性を優先するならデフォルトは無効です。

現在の設定は「2 段組み」ではなく、PC 向けの見開き表示として扱います。見開きは 1 ページ単位で生成したページを左右に同時表示する試験機能です。モバイル/タブレット向けの上下 2 段組みは別機能として設計してください。表示が不自然な場合は、見開きを無効に戻してから原因を見てください。

### オーバーフロー警告

本文が表示枠に収まらない場合、本文エリアではなく body 側の警告として出します。

警告が出た場合は「表示できていない可能性がある」という扱いです。警告を消すためだけに無理な再ページ化を入れないでください。過去に自動補正が原因で、設定を開閉するたびに一行文字数が減っていく問題が起きました。

## 壊れやすい箇所

### 1. 文字数だけでページを切らない

一行あたりの文字数だけでページを確定すると、ルビ、禁則、ダッシュ、三点リーダ、句読点で崩れます。

必ず `sourceStart` / `sourceEnd` が連続していること、表示上の消失がないことを確認してください。

### 2. 設定開閉でレイアウト値を永続的に縮めない

設定画面を開閉しただけで、文字数や行数が小さくなり続ける挙動は不具合です。

調査時は以下を確認します。

- `charSafetyReserve`
- `lineSafetyReserve`
- `fitGuard`
- localStorage に保存された表示設定

### 3. 警告表示を本文の writing-mode に巻き込まない

縦書き中の警告で句点や括弧が回転した場合、警告が本文レイヤーに入っています。

警告は reader content の疑似要素ではなく、横書きの固定 UI として出してください。

### 4. EPUB は TXT と同じ前提にしない

EPUB は HTML 構造、ルビ、章見出し、改行の扱いが作品ごとに違います。TXT と同じロジックを当てる場合も、DOM 化後の構造を確認してください。

## 章判定の現状

対応済みの代表例:

- `■第1話`
- `■第一話`
- `■プロローグ`
- `■幕間`
- `■エピローグ`
- `■終章`
- `一、午后の授業`
- `一．`

注意点:

- 章一覧にルビが混ざらないようにすること。
- 章タイトル抽出時に、本文の改行まで巻き込んで削除しないこと。
- 章ジャンプは「指定章を含むページ」へ飛ぶ実装で十分です。章を必ずページ先頭にすると、レイアウト崩れの原因になります。

## 次に触る人への注意

- 見た目だけ直して、本文が消える修正は絶対に避けてください。
- 「一行こぼれる」「ページを送ると位置がずれる」「設定を開閉すると文字数が減る」は、すべて本文消失につながる危険信号です。

- 実機 Chrome のアドレスバー、ナビゲーションバー、安全領域は Playwright とずれることがあります。最後はスクショで確認してください。
