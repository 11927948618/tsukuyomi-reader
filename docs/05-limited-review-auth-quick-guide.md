# 限定レビュー認証クイックガイド

作成日: 2026-05-28

Cloudflare Access がうまく使えない場合に、Reader内パスワード認証で限定レビュー版を運用するための短い手順です。詳細設計は `06-limited-review-operation.md`、ログの保存先と取得方法は `09-log-coverage-guide.md` を参照します。

## 目的

- 公開版Readerとは別に、限定レビュー版Readerを認証付きで動かす
- 読者ごとに仮IDまたはメールアドレスを登録し、パスワードを発行する
- 認証状態、PW失敗、ロック、同時利用検知を管理画面で見返せるようにする

## 1. Cloudflare Pages の環境変数

限定レビュー版Pagesプロジェクトで、以下を設定します。

```text
TSUKUYOMI_REVIEW_PASSWORD_AUTH=true
TSUKUYOMI_REVIEW_AUTH_SECRET=十分に長いランダム文字列
```

管理画面に入るための認証も設定します。既存互換の管理トークン方式なら以下です。

```text
TSUKUYOMI_ADMIN_AUTH_MODE=token
TSUKUYOMI_ADMIN_TOKEN=管理画面用の長いランダム文字列
```

推奨は管理者メールOTPです。

```text
TSUKUYOMI_ADMIN_AUTH_MODE=email_otp
TSUKUYOMI_ADMIN_EMAILS=halthejuggernaut@gmail.com,haltherock@yahoo.com,weezartherock@gmail.com
TSUKUYOMI_ADMIN_AUTH_SECRET=十分に長いランダム文字列
TSUKUYOMI_ADMIN_EMAIL_PROVIDER=resend
TSUKUYOMI_ADMIN_EMAIL_FROM=Resendで有効な送信元
RESEND_API_KEY=Resend APIキー
```

必要に応じて設定します。

```text
TSUKUYOMI_REVIEW_PASSWORD_DAYS=30
TSUKUYOMI_REVIEW_AUTH_SESSION_DAYS=14
TSUKUYOMI_REVIEW_LOGIN_FAILURE_LIMIT=5
TSUKUYOMI_REVIEW_LOGIN_LOCK_MINUTES=15
TSUKUYOMI_REVIEW_CONCURRENT_WINDOW_MINUTES=10
```

設定後、Pagesを再デプロイします。

## 2. 管理画面を開く

1. 限定レビュー版の `/admin.html` を開く
2. `token` モードでは `管理トークン` に `TSUKUYOMI_ADMIN_TOKEN` を入力し、`保存` を押す
3. `email_otp` モードでは管理者メールを入力して `コード送信` を押し、届いた6桁コードでログインする
4. `限定レビュー認証管理` が読み込まれることを確認する

## 3. 読者を登録する

1. `名前` に管理用の呼び名を入れる
2. `仮ID` の `作成` を押す
3. メールアドレスを使う場合は `メールアドレス` も入れる
4. `状態` は `閲覧許可` にする
5. `一覧に追加` を押す

メールアドレスを伏せたい場合は、仮IDだけで運用できます。

## 4. パスワードを発行する

1. 対象者の行で `PW発行` を押す
2. 表示された平文パスワードを控える
3. 読者へ、限定レビュー版URL、仮IDまたはメールアドレス、パスワードを送る

平文パスワードは発行時だけ表示されます。R2にはハッシュだけが保存されます。

## 5. 読者に送る案内文

```text
限定レビュー版Readerの案内です。

URL:
https://xxxxxxxx.pages.dev/

ログインID:
rv-xxxxxxxx

パスワード:
xxxxxxxxxxxx

このURLとログイン情報は本人確認用です。第三者への共有、転載、スクリーンショット共有、本文コピーは控えてください。
パスワードには期限があります。期限切れやログインできない場合は連絡してください。
```

メールアドレスでログインさせる場合は、`ログインID` をメールアドレスに置き換えます。

## 6. 自分で確認する

1. ブラウザのシークレットウィンドウを開く
2. 限定レビュー版ReaderのURLを開く
3. 認証画面が出ることを確認する
4. 発行した仮IDまたはメールアドレスとパスワードでログインする
5. 作品一覧、本文、表紙が表示されることを確認する
6. ログアウトまたは別シークレットウィンドウで、未認証では作品APIが読めないことを確認する

## 7. 管理画面で見る場所

`限定レビュー認証管理` の一覧で見ます。

- `PW発行済み`: パスワードが発行されている
- `PW期限`: 発行パスワードの期限
- `最終ログイン`: 最後に成功したログイン
- `失敗`: 有効IDでのPW失敗回数
- `ロック中`: 失敗回数が閾値を超えて一時ロック中

`認証振り返り` で見ます。

- `未知ID失敗`: 存在しないIDへの試行件数。生のIDは保存しない
- `今日`: 当日の未知ID失敗件数
- `最終`: 最後に未知ID失敗が起きた時刻

`認証イベント` で見ます。

| 表示 | 意味 | 対応 |
|---|---|---|
| 有効IDのPW失敗 | 登録済みIDでパスワードが違う | 回数が少なければ様子見。多い場合は本人確認 |
| ロック発生 | 失敗回数が閾値を超えた | 本人に確認。必要ならPW再発行 |
| PW期限切れ | 期限切れPWでログインしようとした | 必要ならPW再発行 |
| PW発行 | 管理画面でPWを発行した | 記録として確認 |
| PW発行失敗 | 管理画面でPW発行に失敗した | `secret-missing` なら `TSUKUYOMI_REVIEW_AUTH_SECRET` を設定して再デプロイ |
| PW無効化 | 管理画面でPWを止めた | 記録として確認 |
| PW無効化失敗 | 管理画面でPW無効化に失敗した | 対象のメールアドレスまたは仮IDが一覧にあるか確認 |
| 同時利用検知 | 同じIDで複数セッションが近い時間に動いた | PC/スマホ併用か共有疑いかを確認 |

## 8. 止める・再発行する

一時的に止める場合:

1. 対象者の行で `保留` を押す
2. 必要なら `PW無効化` も押す

完全に止める場合:

1. 対象者の行で `PW無効化` を押す
2. 状態が `停止済み` になったことを確認する

パスワードを再発行する場合:

1. 対象者の行で `PW再発行` を押す
2. 新しい平文パスワードを控える
3. 古いパスワードと既存セッションは無効になる

## 9. 判断の目安

- 未知ID失敗だけが増えている: ボットや雑な総当たりの可能性が高い。生リストを見る必要は薄い
- 有効IDのPW失敗が増えている: IDが相手に届いている、または漏れている可能性がある
- ロック発生がある: 本人の入力ミスか、妨害・流出の疑い。本人確認後に再発行する
- 同時利用検知がある: 本人の複数端末か、共有された可能性。頻度と読書ログを合わせて見る

## 10. 最低限の運用ルール

- 限定レビュー版に賞応募候補を置き、公開版Readerには置かない
- URL、仮ID、パスワードは個別に送る
- パスワードは定期的に再発行する
- 違和感があれば、まず `PW無効化` で止める
- 読者への案内には、閲覧データを管理側で確認する場合があることを明記する
