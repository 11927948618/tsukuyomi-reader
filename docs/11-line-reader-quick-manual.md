# LINE送信用 簡易マニュアル

以下をLINE本文に貼り付けて送ります。

```text
【月読リーダー 立ち読み版 簡易マニュアル】

▼アクセスURL
https://tsukuyomi-reader-tachiyomi.pages.dev/

上のURLをタップして開いてください。
LINE内ブラウザでうまく開かない場合は、Safari / Chrome / Edge などのブラウザで開いてください。

▼ログイン
1. ログイン画面が出たら、別途お知らせした「読者ID」と「パスワード」を入力します。
2. 「ログイン」を押すと、作品一覧が表示されます。
3. 認証中は画面やタイトルに「限定レビュー・認証中」と表示されます。

▼読む
作品一覧から読みたい作品を選んでください。
一度読んだ作品は「栞」が残ります。
次に開く時に「栞から読む」か「最初から読む」を選べます。

▼画面操作
本文をタップすると、上のタイトルや操作ボタンの表示/非表示を切り替えられます。
「設定」から、ページ切替・スクロールを選べます。
ページ切替では、ページめくり効果を「なし / フラッシュ / スライド / 紙影」から選べます。

▼目次・章ジャンプ
作品によっては、本文内の章を自動判別して一覧表示できます。
「構造」から章を選ぶと、その位置へ移動できます。

▼困った時
画面内の「ヘルプ」を開くと、詳しい操作説明を確認できます。
表示がおかしい、作品が更新されない場合は、設定と同期から「強制同期」を試してください。

▼読み終わった後
共有端末や他の人が使う端末では、「ログアウト（認証解除）」を押してください。
```
