# 紙面としての読書画面（0.1.247 草案）

参考画像に合わせ、ページ切替画面の立体的な枠・影を外し、白い紙面と本文を中心にする。上下に画面高の7%（24〜88px）、左右に幅の5%（18〜64px）の基本余白を設け、既存の余白スライダーはその内側の本文幅に引き続き作用する。横書き、暗色テーマ、見開きは既存設定から利用できる。

新規設定のフォントは明朝体。既存の読書設定を一律に上書きせず、「モードとテーマ」の「小説の紙面に整える」で白地・明朝体・縦書き・単ページ・行間1.8・標準サイズへ切り替えられる。進捗バーもこのプリセットでは非表示。既存のタッチ操作で操作UIを再表示できる。

端末のフォントに依存しないよう、Noto Serif JPの400ウェイトをWOFF2へ変換した約3MBの日本語明朝フォントを同梱。ルビ・縦組み用の字形を含む全文字を維持。SIL OFL 1.1の条件と出典をassets/fontsに同梱し、オフライン用キャッシュにも追加。初回取得の転送量が約3MB増える。フォント読込完了時は読書位置を保って組み直す。

検証：既存npm test合格。実Chromiumで390×844、800×1280、1280×800のプリセット適用・明朝フォント読込・縦書きルビ・余白・枠なし・本文の画面内収まり・次ページのsourceStartと前ページのsourceEndの一致を確認した。表示例は自作サンプル文によるもので、参考画像の本文を複製していない。reports/paper-layoutに検査結果と確認用のスマホ・タブレット画像を保存。実機での見え方は未確認。
