# TsukuyomiReader 立ち読みモード 読者向けマニュアル

このマニュアルは、立ち読み用URLを受け取って作品を読む人向けです。

## はじめに

立ち読み用URLをブラウザで開くと、作品一覧が表示されます。

配布されたURLを開くだけで利用できます。アプリのインストールやファイルの準備は不要です。

## 作品を読む

1. 立ち読み用URLを開きます。
2. 作品一覧から読みたい作品を探します。
3. 作品カードの「読む」を押します。
4. Reader画面で本文が開きます。

作品カードには、表紙、タイトル、作者、紹介文、更新日が表示されます。

## Reader画面の基本操作

- `Library`
  - 作品一覧へ戻ります。
- `章`
  - 章一覧を開きます。
- `使い方`
  - アプリ内の使い方を開きます。
- `設定`
  - 文字サイズ、行間、字間、テーマ、縦書き/横書きなどを変更できます。

本文中央付近をタップすると、上部メニューの表示/非表示を切り替えられます。

## ページ移動

縦書き表示では、左右のタップ領域でページを送ります。

画面上部に横スクロールバーがある場合は、つまみを動かしてページ位置を調整できます。

端末や表示モードによって、スクロール操作になる場合があります。

## 表示設定

Reader画面の `設定` から、以下を変更できます。

- 文字サイズ
- 本文フォント
- 行間
- 字間
- 折り返し位置
- テーマ
- 表示モード
- 文字組み

設定は端末のブラウザに保存されます。同じブラウザで再度開くと、前回の設定や読書位置が復元される場合があります。

## 立ち読み用モードでできないこと

立ち読み用モードでは、以下の機能は使えません。

- 手元のTXT / EPUB / HTMLファイルを読み込む
- バックアップZIPを書き出す
- バックアップZIPを読み込む
- 通常のコピー操作
- 右クリックメニュー
- ドラッグ保存

作品は配布者が用意した一覧から読む形式です。

## 著作権表示

画面下部や設定内に著作権表示があります。

```text
© 2026 hal the juggernaut. All rights reserved.
```

作品本文や表紙画像の取り扱いは、配布者の案内に従ってください。

## 画面が古い、または作品が更新されない場合

Library画面の以下を順に試します。

1. `再起動（リロード）`
2. `強制同期（キャッシュ破棄）`

それでも変わらない場合は、ブラウザを閉じて開き直してください。

## 作品が開けない場合

以下を確認してください。

- 通信環境が安定しているか
- 立ち読み用URLが正しいか
- ブラウザを再読み込みしても同じか
- 別のブラウザでも同じか

それでも開けない場合は、作品名と発生した状況を配布者へ連絡してください。

## 推奨ブラウザ

まずは以下の標準的なブラウザで利用してください。

- Windows: Microsoft Edge / Google Chrome
- Android: Google Chrome
- iPhone: Safari（iOS 13以降。目安: iPhone 6s / iPhone SE 第1世代以降）
- iPad: Safari（iPadOS 13以降。目安: iPad Air 2 / iPad mini 4 / iPad Pro以降）

iPhone 6 Plus以前、iOS 12以下、古いSafariでは対象外です。対象外の端末では未対応案内が表示される場合があります。

古いブラウザでは、縦書き表示やキャッシュ更新が正常に動かない場合があります。
