# TsukuyomiReader 立ち読みモード 読者向けマニュアル

このマニュアルは、立ち読み用URLを受け取って作品を読む人向けです。

## はじめに

立ち読み用URLをブラウザで開くと、作品一覧が表示されます。

配布されたURLを開くだけで利用できます。アプリのインストールやファイルの準備は不要です。

## 作品を読む

1. 立ち読み用URLを開きます。
2. 作品一覧から読みたい作品を探します。
3. 作品カードの「読む」を押します。
4. Reader画面で本文が開きます。

作品カードには、表紙、タイトル、作者、紹介文、更新日が表示されます。

同じブラウザで以前読んだ本を開くと、栞が見つかる場合があります。その場合は確認画面が出ます。

- `OK`: 栞から読みます。
- `キャンセル`: 最初から読みます。

栞は1冊につき1つだけ保存されます。読書中に位置が変わると、栞は新しい位置へ自動更新されます。最初から読んだ場合でも、読み進めるとその位置が新しい栞になります。

## Reader画面の基本操作

- `Library`
  - 作品一覧へ戻ります。
- `章`
  - 章一覧を開き、章単位で移動します。
- `使い方`
  - アプリ内の使い方を開きます。Readerから開いた場合は、戻った時に読んでいた位置へ戻ります。
- `設定`
  - 文字サイズ、行間、字間、テーマ、縦書き/横書きなどを変更できます。

本文中央付近をタップすると、上部メニューの表示/非表示を切り替えられます。

## ページ移動

表示モードは、Reader画面の `設定` で選べます。

- `ページ切替`
  - 画面端のタップ領域やスワイプでページを送ります。
  - 左右に余白と枠線がある、ページを読む見た目です。
  - ページめくり効果は `なし` / `フラッシュ` / `スライド` / `紙影` から選べます。
- `スクロール`
  - 通常のスクロール操作で読みます。
  - 文字組みは `縦書き` / `横書き` の設定に従います。

画面上部の読書位置スライダーでは、ページ位置やスクロール位置を調整できます。

表示モードや端末によって、タップ送りよりスクロール操作の方が自然な場合があります。

## 栞

TsukuyomiReaderでは、以前の読書位置を「栞」として扱います。

- 栞は端末のブラウザに保存されます。
- 別の端末や別のブラウザには引き継がれません。
- 立ち読み用の認証設定によっては、本文キャッシュや栞の復元が抑制される場合があります。
- バックアップZIPを使う開発用環境では、ZIP内の栞から再開できる場合があります。

## 章一覧とTXTの構造判定

`章` ボタンを押すと、作品内の章一覧を開けます。

EPUBは、EPUB内の目次情報をもとに章一覧を作ります。

TXTは、本文中の見出しらしい行を自動判別して章一覧を作ります。例:

- `# 第一章`
- `第一章 はじまり`
- `序章`
- `Chapter 1`

自動判別が合わない場合は、Reader画面の `設定` で `TXTの構造を自動判別する` をオフにできます。

## 表示設定

Reader画面の `設定` から、以下を変更できます。

- 文字サイズ
- 本文フォント
- 行間
- 字間
- 折り返し位置
- テーマ
- 表示モード
- ページめくり効果
- 文字組み
- TXTの構造自動判別
- Windowsでホイール上下をページ送りにする

設定は端末のブラウザに保存されます。同じブラウザで再度開くと、前回の表示設定が反映されます。

## 立ち読み用モードでできないこと

立ち読み用モードでは、以下の機能は使えません。

- 手元のTXT / EPUB / HTMLファイルを読み込む
- バックアップZIPを書き出す
- バックアップZIPを読み込む
- 通常のコピー操作
- 右クリックメニュー
- ドラッグ保存

作品は配布者が用意した一覧から読む形式です。

立ち読み用モードでも、公開中の作品については端末内の栞から再開できる場合があります。ただし、限定レビューなど認証付きの環境では、本文キャッシュや自動復元を抑制する設定があります。

限定レビューで `ログアウト（認証解除）` が表示されている場合、それは認証セッションを終了するボタンです。押すと開いている本とローカルキャッシュを消し、ログイン画面へ戻ります。別の読者IDで入り直す時や、読み終わってセッションを閉じたい時に使います。

## 著作権表示

画面下部や設定内に著作権表示があります。

```text

```

作品本文や表紙画像の取り扱いは、配布者の案内に従ってください。

## 画面が古い、または作品が更新されない場合

Library画面の以下を順に試します。

1. `再起動（リロード）`
2. `強制同期（キャッシュ破棄）`

強制同期は、確認画面で実行を選ぶと Service Worker と関連キャッシュを削除してから再読み込みします。作品更新が反映されない時だけ使ってください。

それでも変わらない場合は、ブラウザを閉じて開き直してください。

## 作品が開けない場合

以下を確認してください。

- 通信環境が安定しているか
- 立ち読み用URLが正しいか
- ブラウザを再読み込みしても同じか
- 別のブラウザでも同じか

それでも開けない場合は、作品名と発生した状況を配布者へ連絡してください。

## 推奨ブラウザ

まずは以下の標準的なブラウザで利用してください。

- Windows: Microsoft Edge / Google Chrome
- Android: Google Chrome
- iPhone: Safari（iOS 15以降。目安: iPhone 6s / iPhone SE 第1世代以降）
- iPad: Safari（iPadOS 15以降。目安: iPad Air 2 / iPad mini 4 / iPad Pro以降）

一時的に、iOS 12.5以降はレガシー試用枠として入口を開放しています。レガシー資産のため、本文表示、ページ送り、キャッシュ更新が正常に動作するかは不明です。該当端末では注意画面を確認してから進んでください。

iOS 12.4以下、iPhone 6 Plus以前の一部環境、古いSafariでは対象外です。対象外の端末では未対応案内が表示される場合があります。

古いブラウザでは、縦書き表示やキャッシュ更新が正常に動かない場合があります。
