# Reader Mincho

Noto Serif JPを同梱し、端末の日本語明朝体の有無に左右されずに本文を表示する。UIには適用しない。

出典：https://github.com/google/fonts/tree/main/ofl/notoserifjp
入力Git blob：bd98d809e02880e32f20f1f2a91ef97854f52f57（NotoSerifJP[wght].ttf）
ライセンス：SIL Open Font License 1.1、OFL-NotoSerifJP.txtを参照。

fontTools.varLib.instancerでwght=400に固定し、WOFF2へ変換。文字のサブセット化はせず、ルビ・縦組み用の字形情報を維持する。
