Tsukuyomi Reader の使い方

作品一覧から本文を開いて読むための基本操作と、読書設定・立ち読みモードの挙動をまとめています。

はじめに

  • Library 画面では、公開中の作品一覧から本を開きます。
  • 立ち読みモードでは、管理者が公開した TXT / EPUB / PDF 作品だけを読めます。
  • ローカルファイル読込とバックアップ ZIP 保存は、配布用設定では非表示です。

本を開く

  • 作品カードには、表紙、タイトル、作者、紹介文、更新日が表示されます。
  • 作品カードの「読む」を押すと Reader 画面へ移動します。
  • 栞がある本を開くと、栞から読むか最初から読むかを選べます。
  • TXT は UTF-8 / Shift_JIS の自動判別を行い、本文として整形します。
  • TXT は「第一章」「序章」「Chapter 1」などを見出しとして自動判別できます。
  • EPUB は spine・nav・ncx を見て本文と目次を整形します。
  • EPUB の縦横指定は、本文側の記述と OPF の進行方向から可能な範囲で初期判定します。
  • PDF は固定レイアウトの表示枠で開きます。

Reader の基本操作

  • 上部の「Library」で一覧に戻ります。
  • 「章」で目次を開き、章単位で移動できます。
  • 「使い方」から戻ると、Readerで開いていた位置へ戻ります。
  • 中央タップで上部 UI の表示を切り替えます。
  • ページ切替では、左右タップやスワイプでページ移動します。
  • 縦スクロールでは、通常のスクロール操作で読み進めます。
  • Windows では、設定でホイールをページ送りに切り替えられます。

表示設定

  • 文字サイズ、行間、字間、折り返し幅、テーマを調整できます。
  • 本文フォントは `system / 明朝 / ゴシック` を切り替えられます。
  • 文字組みは `vertical / horizontal / auto` から選べます。
  • 表示モードは「ページ切替」「横スクロール」「縦スクロール」から選べます。
  • ページめくり効果は「なし」「フラッシュ」「スライド」「紙影」から選べます。
  • TXTの構造自動判別は、設定でオン / オフできます。
  • 「400字目安を適用」は、20字×20行に近い見え方へ寄せるプリセットです。
  • 「設定を保存」で本ごとの表示設定を保存します。

栞

  • 読書位置は1冊につき1つの栞として保存されます。
  • 同じブラウザで再度開くと、栞から読むか最初から読むかを選べます。
  • 最初から読んだ場合でも、読み進めると栞は新しい位置に更新されます。
  • 栞は端末内の保存データなので、別の端末や別のブラウザには引き継がれません。

立ち読みモード

  • 通常コピー、右クリック、ドラッグ保存は抑制されます。
  • これは casual copy 対策であり、スクリーンショットや開発者ツールまで完全に防ぐものではありません。
  • 公開中の作品は、端末内の栞から再開できる場合があります。
  • 限定レビューなど認証付きの環境では、本文キャッシュや自動復元を抑制する場合があります。
  • 「ログアウト（認証解除）」は認証セッションを終了し、開いている本とローカルキャッシュを消してログイン画面へ戻ります。

再同期まわり

  • 「再起動（リロード）」は通常の画面再読み込みです。
  • 「強制同期（キャッシュ破棄）」は確認後に Service Worker と関連キャッシュを削除してから再読み込みします。
  • 作品を更新したのに古い表示が残る場合は、強制同期を使ってください。

注意点

  • 本文は現在、全文をまとめて DOM に展開します。
  • 非常に大きい書籍では、初回描画やスクロールが重くなることがあります。
  • EPUB の CSS は安全性と表示安定性のために一部整理しているので、元の見た目を完全再現するものではありません。

配布前チェックリスト

  • Windows / Android / iPhone / iPad で起動し、Library 画面が崩れないことを確認する。
  • iPhone / iPad の公式対応は iOS 15 / iPadOS 15 以降とする。
  • iOS 12.5 以降はレガシー試用枠として一時的に入口を開放する。正常動作するか不明なため、注意画面を挟んでから起動する。
  • 実機がない端末は、ブラウザ開発者ツールのスマホ幅シミュレーションでレイアウト崩れとReader上部UIの開閉を確認する。
  • 作品一覧を開き、長いタイトルや説明が枠からはみ出さないことを確認する。
  • 内部ヘルプが最後までスクロールできることを確認する。
  • Reader の表示設定が最後までスクロールできることを確認する。
  • 本文フォントの `system / 明朝 / ゴシック` 切替が効くことを確認する。
  • 縦書き EPUB と横書き EPUB を1冊ずつ開き、初期の文字組みが極端に外れていないことを確認する。
  • Reader の設定保存後に再度開き、表示設定が反映されることを確認する。
  • 栞がある本を再度開き、栞から読むか最初から読むかを選べることを確認する。
  • ローカルファイル読込とバックアップ ZIP 保存が配布用では表示されないことを確認する。
  • 「再起動（リロード）」と「強制同期（キャッシュ破棄）」のあとも起動できることを確認する。
  • 更新版を上書きした端末で、強制同期後に最新のヘルプと画面が反映されることを確認する。

自家製 EPUB 生成チェック

  • `｜漢字《ルビ》` や `漢字《ルビ》` を、EPUB 化の時点で `` に変換しておく。
  • `…` `‥` `―` `—` のような縦組みで崩れやすい記号を、実機で確認する。
  • `［＃...］` や `〔以下...〕` のような青空注記を、そのまま本文に残すか別扱いにするか決めておく。
  • ASCII 罫線やテキスト記号の区切りを、そのまま本文に残さない。
  • 前付け、本文、底本情報、入力者注を分け、`
    ` 連打だけで見た目を作らない。
  • `font-family` を固定しすぎず、端末標準の和文縦組み字形を殺していないか確認する。
  • 生成後に Windows / Android で開き、ルビ、三点リーダー、ダッシュ、句読点、段落頭を確認する。
